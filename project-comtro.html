Comtro Real-time Communication App

Real-time IoT communication app using MQTT protocol.

Flutter MQTT GetX MVVM IoT WebSocket
Inquire About Architecture

A real-time communication application engineered for IoT device management and hardware monitoring.

Key Features

  • MQTT real-time communication with ultra-low latency topic subscriptions and payload parsing
  • Auto reconnect strategy with exponential backoff for rock-solid network resilience
  • MVVM architecture with GetX for reactive data streams and clean separation of concerns
  • Offline storage utilizing GetStorage for fast key-value caching of device telemetry
  • Responsive adaptive UI tailored for various mobile and tablet screen orientations
  • Device pairing & management with QR code pairing and live status indicators

This project showcases my expertise in real-time communication protocols, IoT hardware integration, and high-performance reactive Flutter architecture.
